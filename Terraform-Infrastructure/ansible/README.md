Ansible EKS Add-ons
====================

This project installs and configures Kubernetes add-ons on an Amazon EKS
cluster using Ansible, Helm, and the `kubernetes.core` collection.

Control machine prerequisites
-----------------------------

Install these requirements on the Ansible control machine, meaning the
machine that runs `ansible-playbook`:

* Ansible `>=2.16`
* Python `>=3.9`
* Helm 3.x
* AWS CLI
* Python Kubernetes client
* The `kubernetes.core` collection listed in `requirements.yml`

The EKS control plane and worker nodes do not need Ansible, Helm, or the
Python Kubernetes client. They only need to run Kubernetes workloads.

Installation
------------

Run these commands from this `ansible` directory:

    ansible-galaxy collection install -r requirements.yml
    python3 -m pip install kubernetes

Verify the control machine setup:

    ansible --version
    python3 --version
    helm version
    aws --version
    ansible-galaxy collection list
    python3 -c "import kubernetes; print(kubernetes.__version__)"

The control machine also needs valid AWS authentication, network access to the
EKS API endpoint, and permission to access the cluster. The
`common_kubeconfig` role uses the AWS CLI to generate the kubeconfig file.

Collections
-----------

The project dependencies are declared in `requirements.yml`:

    collections:
      - name: kubernetes.core
        version: "6.5.0"

The `kubernetes.core` collection provides the modules used to manage
Kubernetes resources and Helm releases, including `k8s`, `k8s_info`, `helm`,
and `helm_repository`.

Running the add-ons playbook
----------------------------

From this directory, run:

    ansible-playbook playbooks/install_addons.yml

The playbook uses the kubeconfig generated by `common_kubeconfig` and installs
the configured add-ons into the EKS cluster.

Security
--------

Do not commit AWS access keys, secret keys, passwords, or other credentials.
Use IAM roles, EKS Pod Identity, IRSA, Kubernetes Secrets, or External Secrets
for authentication and sensitive configuration.
